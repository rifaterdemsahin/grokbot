🧠 First Principles: How 20 Bots Share 1 Physical Machine

Deconstructing the physical and computational bounds of running 20 autonomous agents without thermal throttling, port collision, or memory starvation.

⚡ Event-Driven Idle vs Polling

Zero continuous spin-loops. When bots aren't handling an inbound recruiter ping or scheduled Apify run, their process sleeps. RAM overhead is pinned to static state (~150MB per desktop instance).

🚪 Port Isolation (30,000+ Rule)

Every web preview and API dashboard runs on designated ports above 30,000+ (e.g. 30110, 30080), preventing collision with macOS system daemons and AnyDesk.

🛡️ Sandboxed Virtual Desktops

Each bot occupies its own virtual display workspace and distinct chat context. UI automation, browser tabs, and terminal runs do not cross-contaminate.

🛡️ Backup Agent Architecture: Nous Research Hermes Desktop

Need resilient local failover if cloud APIs experience quota limits or latency? We have installed and built Hermes Desktop on this machine (~/Applications/Hermes.app). It shares workspace state and runs multi-agent pipelines with local or alternate providers.
